Listas de Definición

  • HTTP

    • HyperText Transfer Protocol
    Es el protocolo de red que permite la transferencia de documentos de hipermedia en la red, generalmente entre un navegador y un servidor, para que los humanos puedan leerlos.

  • HTML

    • HyperText Markup Language
    Hace referencia al lenguaje de marcado utilizado en la creación de páginas web.

  • URL

    • Uniform Resource Locator
    Una URL es una dirección que es dada a un recurso único en la Web.

  • TCP/IP

    • Transmission Control Protocol/Internet Protocol
    Es un conjunto de reglas estandarizadas que permiten a los equipos comunicarse en una red como Internet.

  • Internet

    • Red informática mundial, descentralizada, formada por la conexión directa entre computadoras mediante un protocolo especial de comunicación.

  • W3C

    • World Wide Web Consortium
    Es uma organización internacional que tiene como objetivo crear estándares para la World Wide Web.

  • Mozilla Foundation

    • Es una organización sin ánimo de lucro dedicada a la creación de software libre.
