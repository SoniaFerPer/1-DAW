Ejemplo de la etiqueta video

Para utilizar elementos de video en una web se deben emplear los siguientes atributos

  • src: define la URL donde se aloja el contenido de audio.
  • type: define el formato del archivo.
  • controls: deberá especificarse o NO aparecerá ningún elemento visual para controlar la reproduccion del contenido.

También usaremos los atributos width y height para configurar el tamaño del reproductor del video, pero esto es opcional.
